## The entry

`main.py` writes exactly one line (96 characters) to `/output/entry.txt`:

> I finally read the terms and conditions. Turns out I've been married to a free trial since 2019.

## Why this line

The judge weighs surprise first, then economy, freshness, and clean wording. The line opens on the most boring chore imaginable — reading terms and conditions — and the second sentence twists it into an accidental marriage to a free trial: a legal-commitment punchline nobody sees coming from a software chore, in 96 characters, with no stock joke format and no setup longer than the punch needs.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
